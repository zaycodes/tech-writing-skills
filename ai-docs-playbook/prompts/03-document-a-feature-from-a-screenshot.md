# Document a feature from a screenshot

Attach the screenshot, then run both steps in one chat. Workflow 03 in the AI Docs Playbook.

```text
STEP 1 — Inventory only (no documentation yet):
I'm attaching a screenshot of <feature/screen>. List the UI elements (panels,
fields, buttons, tabs) with their labels and apparent purpose. Flag anything you
can't read clearly as "LOW CONFIDENCE." Do NOT infer behavior that isn't visible
(what happens on click, error states, logic) — list those as "needs verification."

STEP 2 — Draft from the inventory:
Using that inventory, draft a how-to page with these sections:
- Prerequisites
- About (one sentence: what the feature does)
- Steps
- Learn more

Fill only what the image supports; for anything unconfirmed,
insert "[VERIFY: …]" rather than guessing.
```
