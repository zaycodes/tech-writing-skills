# Turn a support conversation into a doc ticket

Paste the full, unedited support conversation into the placeholder. Workflow 02 in the AI Docs Playbook.

```text
Create a documentation ticket from the conversation below.

Give me a TITLE and a DESCRIPTION with these sections. Under each heading, keep
the line "Generated by AI – review for accuracy."

## Summary
- User's Core Question: what was the user confused about?
- Root Cause of Confusion: why are the current docs insufficient or misleading?
- Proposed Documentation Solution: what specifically should change?

## Justification
Why this matters: business value, reduced support load, user self-service.

## Recommended Updates
Specific, actionable changes. Draft the exact section text only if I've given
you the relevant docs; otherwise say the existing docs need review first.

Relevant docs: <paste links, or write "none — needs review">

Conversation:
<paste the full thread>
```
