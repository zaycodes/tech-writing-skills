# Scaffold and restructure pages with templates

The two page templates, then the prompt that restructures an existing page into one of them. Workflow 04 in the AI Docs Playbook.

```text
HOW-TO (one procedure per page):
  Title (e.g. "Creating an X")
  ## Prerequisites
  ## About
  ## Steps
  ## Learn More

CONCEPT (one idea per page):
  Title
  ## How It Works
  ## Get Started   (links to the related procedures, in order)
  ## Learn More
```

```text
Restructure the page below into the <how-to | concept> template. This is a
STRUCTURE-PRESERVING first pass, not a rewrite.

- Map each existing "##" heading to a template section; show me the mapping.
- Content before the first heading becomes the intro.
- Anything that doesn't fit a section goes under a literal "## Additional notes"
  section — never drop or silently merge content.
- If the page is doing more than one job, recommend splitting it by type.

Page: <paste the full current page>
```
